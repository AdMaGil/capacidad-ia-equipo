Capacidad incremental con IA

Modelo de tareas (no sesiones): separa capacidad potencial de capacidad ajustada, con factores de confianza, calidad y reinversión.

1Instrucciones para el equipo

Cada persona lanza este prompt en su propia IA (Claude, ChatGPT...), copia el JSON que devuelve y lo pega en la sección "Aportar mis datos" de abajo. El esquema es el mismo para cualquier IA — así los datos son comparables entre fuentes.

Ver / copiar el prompt clic para desplegar

Escala de factores del prompt: confidence_factor 1.00 medido / 0.75 comparable observable / 0.50 solo conversación / 0.25 información limitada / 0.00 imposible. quality_use_factor 1.00 usado y validado / 0.90 con correcciones menores / 0.50 uso parcial / 0.00 descartado. capture_factor 1.00 con evidencia explícita de reinversión / 0.50 potencial sin evidencia / 0.00 sin resultado útil. Si una tarea no trae estos campos, el artifact aplica valores conservadores por defecto y lo marca en el detalle.

2Aportar mis datos

Los envíos se fusionan por task_id dentro de la misma persona+fuente+periodo: reenviar no duplica tareas ya registradas, solo actualiza las que cambien. Si una tarea no trae factores de confianza/calidad/captura, se le aplican valores conservadores por defecto (marcados en el detalle).

3Filtro de análisis

Aplica a todo el análisis de abajo (lectura ejecutiva, categorías, escenarios y detalle). Sin selección = todo el equipo.

4Lectura ejecutiva

La capacidad potencial refleja el tiempo teóricamente liberado por la IA. La capacidad ajustada aplica correctores de confianza, calidad y reinversión para ofrecer una estimación más prudente. No equivale a ahorro económico ni a output adicional demostrado.

6Escenarios de equipo (proyección)

Proyección = FTE elegibles × capacidad × % tareas elegibles × % adopción × % reducción de tiempo × % captura. No equivale a reducción de plantilla — es volumen de trabajo adicional absorbible con la misma plantilla. Presentar como proyección hasta validar con datos observados.
